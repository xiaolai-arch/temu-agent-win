# store-switch（账号切换式多店铺）— 发现会话（2026-10-12/13 实测定稿）

## 模式定案

多店铺 = **同一浏览器内切换登录账号**（每店一个手机号+密码）。
账号：main=hpoiZee(151…)、store-b=boliooZ(134…)、store-c=lecoddebujbrjq(152…，首登自动学习)。
**执行入口**：`python driver/switch_store.py <store-id>`（确定性脚本，不依赖 agent）。
2026-10-13 实测：main→b→c→main→… 五连切全部成功，每店 ~115-145s。

## 完整链路（2026-10-13 早定稿，全程程序可操作 ✅）

### 1. seller 登录（全自动，~45s）

干净 `/login`（已登录也直接出登录页）→ 「手机号登录」tab →
手机号框 `^a` 重打 → **点手机号框→Tab→`^a`→密码**（Tab 法，密码框无法坐标点击）
→ 「登录」按钮（OCR 定位）→ **「同意并登录」确认层**（点登录后弹出）→ 完成。
登录成功后常弹 **Edge「保存密码？」气泡**（盖住页面右侧，干扰 OCR/点击）→ 点「以后再说」关掉。

### 2. Agent Center 联动（授权链路 = 用户正常流程的程序化）

seller 与 agentseller **会话独立**；授权良好时导航 customize-goods 自动联动；
否则走用户指点的正常路径（**全程可点，无免疫页**）：

```
seller 主页 site-main
  → 侧边栏「商品管理」展开（「定制商品内容」子项在 (41,1203) 一带）
  → 点「定制商品内容」→ 页面弹授权卡：
      「即将前往 SellerCentral（全球）的「X」店铺」
      + 协议勾选行（勾选框在行首左侧 ~28px）
      + 「确认授权并前往」按钮（深色文字，OCR 可读）
  → 勾协议 → 点「确认授权并前往」
  →（Agent Center 挂着别店时）「确认切换」弹窗：
      「SellerCentral 当前已有登录中的店铺，确认切换吗」（当前 X → 即将切换为 Y）
      确认按钮 = 白字蓝底（OCR 读不出文字！）→ 用「不切换」行定位 + 像素级蓝色块检测点其左侧
  → 定制商品内容页打开（新标签）→ 账号 + 双按钮验证
```

### 3. 店名验证（防跑错店 = 最高风险控制）

- **主源**：seller 主页右上角账号名（大字，OCR 稳定）；授权卡标题「即将前往…的「X」店铺」兜底
- OCR 混淆归一化：№→li（boliooZ 常被读成 bo№oZ）、I/1→l、0→o，再比对
- 定制商品页右上角账号名**小字时好时坏** → 裁剪放大重读 + 链路捕获名兜底
- 未知店首登：读到**别家已知店名**也必须走联动（防假阳性跑错店）；成功后自动把店名
  写进 local.config.json `accounts.<id>.name`（下次严格校验）

## 免疫页地图（血泪总结）

- 「选分区」并不存在独立页：它是授权卡的一部分（请选择分区：欧区 / 全球（除欧区、美国）），

- 验证码滑块（登录过频/连点会触发）→ 红线：程序绝不碰，exit 2 报告人工

## 脚本退出码

0=成功（店名✓ 双按钮✅）/ 1=环境或页面异常 / 2=验证码或账密错（人工）/ 3=验证失败（重跑一次通常恢复）
