## 登录链路（seller.kuajingmaihuo.com）

1. `/login` → 点「手机号登录」tab → 表单 `input[name="usernameId"]` + `input[placeholder="请输入密码"]`
   - 浏览器会**预填上一次的号码**（本地是 151/main 的）——`page.fill` 直接整体替换，安全。

2. 勾「我已阅读并同意」→ 点「登录」→「同意并登录」确认层（evaluate click 可点）

   必须到 `agentseller.temu.com/auth/authentication` 点「中国地区」卡片 → 弹 SSO 小窗：
   - 小窗授权卡：勾选框是 **12×12 可见方块 + 0×0 隐藏 input**（`CBX_square`/`CBX_input`），
     **必须 raw mouse 点方块几何中心**（page.click 选择器歧义、native-setter 合成事件都无效）

## 调价弹窗 DOM（newon/product-select 查询 SKC → 发起调价）

- 入口「发起调价」：叶子 span，**在视口外时必须先 scrollIntoView 再 raw click**
  （ego 的 page.click 会自动滚动，raw click 不会——第一批失败根因）
- 弹窗根：从「确认调价」按钮向上走到含 "SKC ID" 且有 checkbox 的祖先。
  头部有 `SKC ID: <数字>` 可精确匹配目标。
- 行 = 含 `<qty><单位>` 文本且有 checkbox 的 `tr`：
  - 数量：`(\d+)\s*(?:pcs|件|张|片)`；现价：`¥(\d+.?\d*)`；作废行：文本含「已作废」且 input disabled
  - 勾选框：`input[type=checkbox]`；输入框：行内非 disabled 的 `input[type=text]`
- **填值**：native setter + input/change 事件（React 受控，已验证回读一致）
- **勾/取消勾选**：合成事件无效（同 AC 门勾选框），必须 raw click 可见方块
  `CBX_checkbox` 下的 `CBX_square` 几何中心
- 提交：点「确认调价」→ **弹窗关闭 = 成功**（唯一信号）；失败自救 = 取消「勾选但空值」的行
- 行计划（同 grind_one）：作废/未勾选→跳过；qty<10→取消勾选；现价≤建议价×1.05→取消勾选；其余填 `sug(cat,qty)`

## ⚠️ 头号陷阱：窗口最小化 = 一切交互假失败（2026-10-24 深夜定论）

症状组合（极易误判成「平台风控/锁价」）：
- 填值当场写入成功，700ms~2s 后被抹回空
- 勾选框点不动 / 行「消失」/ 查询返回 0
- 按钮坐标变成负数或 (32, 0) / elementFromPoint 返回 null
- 截图报 "Cannot capture a screenshot while the window is minimized"

唯一判据：`page.evaluate(() => ({ iw: innerWidth, ih: innerHeight }))` → **0 = 窗口最小化**。

原因：视口 0×0 → 布局瘫痪 + React 渲染停摆 → 所有受控组件写入被回滚。
ego 进程退出后窗口常被最小化，且**标题会变成「首页 - ego」等非 temu 文案**，
所以恢复脚本的窗口匹配要按 `*ego*`，不能按页面标题。

恢复：`win.ps1`（C# Add-Type + ShowWindow(h, 9)），已内置到 grind_lib.ensureWindowVisible()。

## 引擎实现要点（grind_lib.mjs，2026-10-24 深夜最终版）

1. **填值**：给目标 input 打 `data-grind-target="1"` → `page.fill('css=input[data-grind-target="1"]', v)`
   （真实键盘级输入，React 受控组件认；索引/ref 映射会因重渲染漂移，已弃用）。
2. **正则**：`page.evaluate(\`...\`)` 里传字符串时，源码必须写 `\d`、`\s`（单写会被模板字符串吃掉）。
3. **勾选框**：`wrap.querySelector('[class*="CBX_square_"]')`
   ——用 `[class^="CBX_square"]` 会抓到 `CBX_squareInputWrapper`，点了无反应。
4. **弹窗稳定**：匹配成功后等 5s 再操作（刚打开时 React 未稳定，填充会被回滚）。
5. **提交前 sweep**：只允许降价；建议价 > 现价的行必须**取消勾选**（涨价会被平台拒：
   「请关注调价原因」）。
6. **rowBbox 必须 return**（曾经漏掉 → 取消勾选 100% 失败，日志报 box gone）。
7. 查询前：取消「商品信息待确认」等待办筛选 + `window.scrollTo(0,0)`
   （页面滚动位置坏了会让按钮坐标变负）。
