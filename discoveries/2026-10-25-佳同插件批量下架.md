# 佳同插件 · 批量下架商品（不限次数，2026-10-25 用户告知 + 界面截图）

> 替代客服自助工具的「每日 2 笔」限额流程。用于钢印等大批量亏损下架。

## 入口

上新生命周期管理页（`agentseller.temu.com/newon/product-select`）→ 佳同插件浮窗
→ 「**批量下架商品**」弹窗（标题栏：佳同跨境 批量下架商品 / 查看教程帮助）

## 弹窗结构（2026-10-25 截图实测）

- 顶部三个范围 tab：
  - **当前勾选 (N)** —— 下架列表页勾选的商品
  - **当前搜索条件下的商品** —— 按页面筛选结果全量
  - **按照表格下架商品** —— 上传 Excel（本任务用这个）
- 表格范围下有三个子 tab：`spu` / `skc` / `sku`（按 ID 类型）+ 「下载示例表格」
- 上传区：「点击上传表格」
- 右上「开始下架」按钮
- 下方「下架结果列表」：商品图片 / 商品名称 …（逐条结果）
- 底部「关闭」

## 表格格式

- 单列，表头就是 `SKC ID`（sheet 名随意，示例为 sheel1）
- 示例文件：`C:/Users/34191/Downloads/下架商品表格.xlsx`
- 本任务生成：`research/store-data/delist-stamp-batch-store-c-2026-10-25.xlsx`
  （59 个钢印 SKC，已剔除 10-24 通过客服工具下架的 2 个）

## 执行步骤（ego 版，待首次实操验证）

1. 打开上新生命周期管理页 → 等佳同浮窗注入（弹框已恢复=可正常弹窗）
2. 点「批量下架商品」→ 切到「按照表格下架商品」→ 子 tab 选 `skc`
3. 「点击上传表格」→ `setInputFiles` 上传 xlsx（若是 file chooser，用 waitForFileChooser）
4. 点「开始下架」→ 等「下架结果列表」逐条出结果
5. 结果核对：列表内的商品名/图片即成功项；失败项需记录
6. **最终以导出复核为准**（商品状态=已下架/已终止）

## 注意

- 与调价任务共用同一浏览器 → **必须串行**，调价批次跑完再下架
- 下架不可逆（会连链接一起废掉），钢印确认口径：售价 < 保本价 (25×qty+9)/0.8
- 佳同浮窗若挡住页面元素：点浮窗关闭或等其自动收起（右下角「弹框已恢复」开关状态）
