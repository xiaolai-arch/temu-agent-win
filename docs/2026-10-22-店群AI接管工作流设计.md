# 店群 AI 接管工作流设计(LinkFox Skills × temu-agent)

> 2026-10-22 | 基于 skill.linkfox.com 295 技能盘点(见《linkfox技能全量盘点.md》)
> 结论:**Temu 侧写操作全面 API 化**,速卖通采集保留浏览器插件,合规前置防封店。

## 一、设计原则:三条车道分工

| 车道 | 工具 | 理由 |
|------|------|------|
| **写操作 → API** | LinkFox Temu 官方 API 技能(发品/改价/库存/订单/发货) | 快、稳、无验证码、无风控弹窗,替代浏览器点击 |
| **采集 → 保留浏览器** | 现有 ali_collect.py + 妙手ERP插件采集 | 速卖通反爬,链接采集服务端抓不动(discoveries/2026-10-18 已验证),LinkFox 也无速卖通技能 |
| **读数据/合规 → API** | GeekBI/电霸/睿观/1688 数据技能 | 浏览器看竞品数据慢且看不全,API 一次拉全 |

兜底:任何 API 失败(限流/算力不足/token 过期)→ 回退 temu-driver 浏览器链路。

## 二、主工作流:上新流水线(采集 → 找货 → 合规 → 上架)

```
[1 选品]  geekbi-temu-market-research(类目蓝海指数/关键词趋势)
          geekbi-temu-shop(对标店铺动销/客单价)
              ↓ 给出候选类目/商品清单
[2 采集]  现有链路:速卖通浏览器插件 → 妙手公用采集箱(唯一可靠通道,不变)
          补充:geekbi-temu-search-by-image(Temu 以图搜同款,查重复度)
              ↓ 商品图 + 标题 + 价格
[3 找货源] 1688-search-by-image(商品图 → 1688 货源:价格/起订量/复购率)
          1688-product-detail(确认 SKU/发货地)
              ↓ 核算利润:Temu 售价 − 1688 货源 − 物流 ≥ 阈值才继续
[4 合规]  ruiguan-detection-patent-design(外观专利,相似度≥0.7 或有 TRO → 弃)
          ruiguan-text-trademark / trademark-graphic(标题词与图形商标)
          ruiguan-copyright-detection(主图版权)
              ↓ 通过的进发品队列(带风险分级标签)
[5 上架]  temu-category-search(类目 ID)
          linkfox-temu-add-product-us:
            us_goods_attrs / variation(类目属性规格)
            us_goods_image_upload(图片)
            us_goods_add(temu.local.goods.v2.add 发品)
              ↓ 替代「忆托ERP同步/按勾选同步」浏览器按钮
[6 验证]  us_goods_list / us_goods_detail 回查上架结果与供货价
```

## 三、日常运营工作流(接管后)

| 场景 | 技能/脚本 | 节奏 |
|------|-----------|------|
| 订单处理 | temu-order-us → fulfillment-us(面单/发货) | 每日 |
| 动态定价 | temu-price-us(定价单+批量改价,配合 GeekBI 竞品价格) | 每周 |
| 库存上下架 | temu-manage-product-us(滞销下架、断货停售) | 每周 |
| 售后 | temu-returns-refunds-us / temu-cancel-order-us | 每日 |
| 广告 | temu-ads-us(报表→调预算) | 每周 |
| 促销 | temu-promotion-us(活动报名) | 跟随平台节奏 |
| 合规复查 | temu-compliance-global + 睿观 | 平台预警时 |
| 标题优化 | product-title-analyze(结合标题白名单,防词池退化) | 每月 |

切店:API 用 storeKey 区分店铺(store-b/c/d/main 各自 token),**浏览器切店(switch_store.py)仅作采集用**。

## 五、成本与安全红线

- **算力计费**:失败/空结果禁止自动换词重试翻页(技能内置约束);批量任务先小样试算再放量
- 沿用项目安全红线:凭据只存 local.config.json 或 token store;日志不打印 token 值
- 写操作(API 发品/改价)默认需用户在对话中确认;读操作(订单查询/数据)可直接跑
- 速卖通侧不变:插件采集 + 妙手ERP,本工作流不触碰
